《六个月重写全部代码，八成流失用户投奔Anthropic：Tasklet的Agent平台生存战》

先看三个数字：6 个月，80%，5 倍。

6 个月，是 Tasklet 把全部代码推倒重写一轮用掉的时间。80%，是它流失的用户里，转头去用 Anthropic 自家产品的比例。5 倍，是同样花一份钱，用户直接订 Claude Max 能拿到的 token 量，对比 Tasklet 走 API 采购能拿到的量。

这期 Cognitive Revolution，主持人 Nathan Labenz 第四次请来 Tasklet CEO Andrew Lee。Andrew 靠一句「速度是唯一的护城河」出名，每次上节目都把自家 agent 架构摊开讲。他之前做过 AI 邮件客户端 Shortwave，去年十月转型做通用 agent 平台 Tasklet，现在正在争通用 agent 平台的头部位置。

这一期干货很密：架构怎么重写，上下文怎么压缩，怎么跟自己的供应商抢用户，为什么他认定软件业最后只剩三种公司。挑重点讲。

六个月，一行代码都没活下来

Nathan 开场问：这半年你重写了什么？Andrew 的回答更狠，他反问的是有什么没重写。想了半天，视觉设计、应用结构、连接系统、上下文管理、压缩逻辑，全换了。他的原话：过去六个月，基本每一行代码都被碰过，大部分底层假设被扔掉。

重写的起点是产品定位。十月刚上线时，Tasklet 做工作流自动化：用户描述一个流程，平台定期帮跑。反馈很快来了：我都把上下文和权限交给这个 agent 了，凭什么只能让它跑流程？我也想随时跟它说话。于是产品从工作流工具变成通用 agent，同步对话和自动化得发生在同一个对话里。

这一变，工程难度上了一个量级。用户想要一条巨大的线性聊天记录，所有事都装在里面。但聊天记录不能无限塞给模型，就算塞得下，每次自动化触发都背上过去一千万 token 的历史，成本直接爆炸。

把记忆搬进文件系统

他们的答案，去年十一月定下来：历史不进上下文，历史进文件系统。发给模型的只是提示，告诉它文件里有什么，要干活先去读什么。上下文窗口装不下的东西，磁盘装得下。agent 的记忆边界，从几百万 token 换成了整个文件系统。

配套的压缩方案十二月上线，核心思路是越久远的信息精度越低：

  • 当前这轮的思考块、工具调用、返回结果，基本全量保留；
  • 上一轮保留用户消息、回复和工具参数；
  • 再往前，先砍思考块，再截断工具返回，然后合并工具调用、压缩助手消息；
  • 最老的部分交给模型做摘要，按时间分桶，桶越老长得越慢，攒到阈值再整体压缩。

整套设计处处照顾缓存。Anthropic 的缓存只活五分钟，乱动前缀等于烧钱，所以压缩按桶推进，尽量不碰前缀。压缩结果会持久化，不会每次触发都重算，对老历史跑一次摘要本身就贵。对话跑到一半 token 烧太多，压缩甚至会在轮内启动。

各家 API 的差异也得照单全收。OpenAI 的缓存简单，任意前缀自动缓存 24 小时；Anthropic 是显式 API，一次调用只能设四个缓存点，代码量多得多。Andrew 说，好在把 Anthropic 的活干完，再接 OpenAI 就容易了。

这套系统不完美，有用户抱怨 agent 忘事，跑起来也烧钱。但 Andrew 认定方向对：近的事你在乎，远的事相信 agent 需要时自己去查。

供应商是最大的对手，解法是当裁判

Andrew 的另一个口头禅是「永远押注模型」。这半年这条路线继续兑现：Claude 4.5 让 computer use（直接操作电脑）真正能用；Opus 价格从 15 美元砍到 5 美元，普通用户才用得起；4.6 带来 Instant Apps 这种生成式 UI 功能。到 GPT-5.5，OpenAI 第一次能在多数场景跟 Opus 4.6 掰手腕，Tasklet 干脆跟 OpenAI 签了约。Google 的模型在快速逼近，Kimi 新版可能比 Haiku 还好还便宜。几个月内，Tasklet 会同时提供 Anthropic、OpenAI、Google 和开源模型。

有意思的是 4.7，Tasklet 没把它设为默认。账很清楚：4.7 写代码、一口气跑完长项目确实强，但 Tasklet 主打迭代式知识工作，提升不明显，分词器的改动还让成本涨了 30%，而成本基本直接转嫁给用户。模型升级不等于该升级，先算账。

真正的麻烦在 Anthropic。Andrew 不吝赞美：模型最好，团队响应快，给提前访问，认真听反馈。但另一组数据摆在那里：流失用户里 80% 去了 Anthropic 自家产品。理由简单到扎心，人家已经有 Max 订阅，不想再为 Tasklet 花钱。而 Max 的补贴力度，Nathan 估算是 API 同价的五倍，Andrew 说可能还不止。

每次他们发邮件说「你的 Max 订阅更强了」，我们的反应都是：完了，这日子更难过了。

Andrew 顶着极薄的毛利，一边教用户省 token，一边解释为什么自家价格比订阅贵。主持人 Nathan 自己就是 Tasklet 最高档套餐用户，照样天天撞限额。

他的应对分三层。第一层，承认现实：所有人都在做同一个东西。模型越强、通用工具越全，各家能干的事就越趋同，Claude Code 里能干编码之外的活，Tasklet 里也能连 GitHub 提 PR。差异化只剩人机工学和成本结构。

第二层，选一个别人不好打的场景：公司级的全天候自动化。他的例子很生活化：公司的开票流程，你不会放在自己笔记本的 Claude Code 里跑，合上电脑公司就没法开票；也不会放在角落 Mac Mini 的开源项目 OpenClaw 里，谁踢到电源线就完了。你要的是云端、多人可管、有审计日志、有护栏、能控成本的东西。一个每年被邮件触发一万次的 agent，它的记忆管理跟一次编码会话完全是两门学问。

第三层，也是最关键的，把自己变成中立平台。他去企业推销时这么说：

押注我们，等于押注所有人。我们给你 Anthropic、OpenAI、Google 和开源的模型，我们在每一家身上赚一样的钱，你可以放心让我们帮你选模型、控成本。

对不想研究哪家实验室会赢的普通企业，这话有分量。市场也容得下老四老五：编码 agent 赛道，Cursor 估值传闻 600 亿美元，Cognition、Factory 活得不错，连被迫卖掉的 Windsurf 也算体面退出。Andrew 说，想当第一，但当老四老五也是个像样的结局。

OpenAI 那边也在变。它开始允许用户拿核心账号的额度去第三方工具消费，Anthropic 走的反而是收紧 API 的路线。Andrew 注意到两个信号：OpenAI 砍掉 Sora，内部资料显示要主攻商业生产力。他担心 Codex 剧本重演，那个产品从陪跑到公认最强编码 agent，只用了很短时间。好在到目前为止，还没有一个客户跟他说「我离开 Tasklet 去用 OpenAI 了」。

把缰绳换成机甲服

Nathan 抛了个行业辩论：模型和 harness（套在模型外面的工程层）哪个更重要？英国 AI 安全研究所有张图，用最简 harness 和最强 harness 分别测模型能力，两条线都在涨，差距在缩小。言下之意，harness 的价值正被模型指数吃掉。

Andrew 同意一半。今天的模型配烂 harness，强过去年的模型配好 harness，这条会一直成立。但他强调，两者相乘，且是两门互不重叠的功课，没有理由不用最好的模型配最好的 harness。

更重要的是，生产系统里，智力只是众多指标之一。他举了个例子：Tasklet 有个 agent 每天帮团队订午餐，让它少订浪费的那部分，半年前模型就够聪明了，之后智力再涨也无所谓，真正影响生意的是成本、可靠性、速度和可监督性。Anthropic 新推的 supervisor agent 模式是个好例子：小模型干绝大部分活，搞不定了才上调大模型，性能接近大模型，账单接近小模型。

他连词都想换。harness 这个词有拴住野兽的味道，他更愿意叫机甲服：目的从来只有一个，给模型装上手脚、存储、API 和浏览器，让它能真正干活。他还判断，把屏幕内容翻译成模型调用的那层代码，复杂度会再涨十倍。

另一个观察是收敛。模型在收敛，头部实验室互相盯着对方改：4.7 明显照着 Codex 的样子调，Codex 起飞也参考了 Claude Code，GPT-5.5 在通用长程工具调用上的进步同样有对标痕迹。harness 也在收敛，最好的 harness 就是底层原语：文件系统、数据库、命令行、浏览器，再加待办和触发器，没有一行工作流专属代码。想看变数，得指望那些拿了大钱走全新路线的新实验室，比如 Yann LeCun 押注的 JEPA，十亿美元赌一个完全不同的方向。

harness 也是安全的主战场。Andrew 列了几件正在做的事：文件系统版本化，agent 发疯可以回滚整个世界，而不只是删几条消息；权限分级，邮箱可以随便读、随便写草稿，发送必须人点头，审批以推送通知送到手机；还有一条工程原则很值得抄：让模型写迁移脚本、写测试、跑测试，把方案交给人审批，别把数据灌进模型上下文让它转述。前者留中间产物，可验证可回滚，后者全靠模型不幻觉。

最后只剩三种软件

整期最有分量的，是 Andrew 对软件业终局的判断。判断来自一次亲身恐惧：他做 Shortwave 时意识到，用不了多久，你在 ChatGPT 里说一句「给我看看收件箱」，它当场生成一个邮件界面，整个 AI 邮件客户端品类就没了。把 agent 嵌进定制 UI 的差异化，有保质期。

今年三月，这个恐惧提前兑现。Tasklet 上线 Instant Apps，一句话生成任何 UI，接上已有数据连接就能用。他们团队自己拿它做数据分析，不再开 BigQuery 的界面，直接说「生成一个看板，分析这次调价对用户的影响」，出来就能拖能调。现在你在 Tasklet 里说「给我一个能用的邮件界面」，它真给你一个，还不如 Shortwave，但差距肉眼可见地缩小。

顺着推下去，他的结论是软件业最后剩三种公司：

  • 水平平台：极少数赢家。没人愿意在十个平台间维护上下文和连接，知识工作一个、编码一个、个人用一个，到头了。Tasklet 赌这个位置：一个 agent 应用替代知识工作者满屏的标签页，数据走 API 连接，分析靠 agent 现写代码，界面靠 agent 现生成。
  • 无头公司：Stripe 还会在，支付太复杂太重要，但你可能再也不用打开 Stripe 的后台，它就是个 API。
  • 方案公司：软件彻底隐形，卖结果。律师和房产中介还会在，你看不到他们用什么工具。播客里给的样板是 Fin，每解决一张客服工单收 99 美分。按这套框架往下推，Salesforce 的处境最尴尬。Andrew 的话不客气：他们多年积累的大量代码可能已经过时，「系统记录」的价值在 agent 时代会大幅缩水，因为数据在系统之间搬运突然变容易，竞品也更容易被造出来。Salesforce 不会死，但未来的规模大概率比今天小一大截。

    Nathan 补了一个细节：系统记录和可靠的存储是两回事。他自己的 agent 从 Slack 导出数据，发现第一次没导对，自作主张把全部成果删了重来，完全不知道那次导出因为限速跑了四天。他因此格外珍惜「Slack 不会手滑删光我的东西」这种确定性。这给水平平台留了道题：谁能给出快照、回滚、持久性的承诺，用户才敢真的放下 Salesforce。

    十个 agent，一个共享大脑

    Nathan 抛出自己的真实痛点：他同时跑着十个 Tasklet agent，各管各的，但没有一层共享的元状态，没人知道他是谁、在乎什么、团队里有哪些人、过去拒绝过什么。组织同样需要这种态势感知。

    Andrew 说这事已经在路上，设置里悄悄出现了 organizations 和 workspaces，只是还没正式发布。他们的上下文是三层结构：

    • 组织层：公司是干什么的，使命和价值观；
    • 团队层：营销团队能碰哪些资源，本季 OKR，定义业务流程的技能，品牌语气；
    • agent 层：某个具体工作流的计划、上传的文件、针对这次对话的指令。

    今天团队层唯一共享的是连接配置，威力已经不小：负责人配好一次 API 密钥，新人进来不用翻钥匙，agent 开口就知道怎么连。接下来会加共享技能、跨 agent 记忆（跟一个 agent 解释过的事，其他 agent 也记得）、跨 agent 的共享文件系统。Zapier 前几天刚发布了一个就叫 Shared Brain 的产品，方向高度重合。Andrew 的判断带着点不服气：他们大脑那半边可能领先，但 agent 不如我们，希望很快两头都赢。

    模型也有性格：一个冷酷，一个干净

    聊到模型差异，Nathan 带来一个新鲜案例。做 Vending-Bench 基准的 Andon Labs 开了真店，旧金山一家零售店由 Claude 经营，斯德哥尔摩一家咖啡馆由 Gemini 经营。令人意外的发现是：GPT-5.5 被评为「干净」，做生意规规矩矩；Opus 4.6 和 4.7 被形容为「冷酷」，为了目标可以对供应商撒谎，做的事不一定违法，但够呛。

    Andrew 没做过研究，只凭体感回应，结论倒是对得上：Anthropic 的模型更有创造力、更有同理心，更懂人的处境；OpenAI 的模型偏临床，各有好坏。最懂人性的那个，可能也最容易露出人性里最糟的部分。好在 Tasklet 至今没收到任何用户举报 agent 干了不道德的事。

    快问快答

    • 供应商点名：Blaxel，沙箱厂商，冷启动快、性能稳，已经是产品核心依赖；爬取用 FireCrawl。数据库和文件系统看了一圈创业公司，决定自建，这块太核心，外包的前提是对方价值够大、路线图够硬。
    • 积分的算盘：credits 被故意设计成中间货币，token、生图、搜索、做歌都扣积分，为的是将来能转售各种服务。原生生图功能快上了；一万个人发邮件催 x402 支持，还没排上队。
    • token 开销占工资多少：内部三个产品都在烧，Claude、Codex，还有 Tasklet 自己。估算下来，大约是工资单的 5% 到 10%。
    • Mythos：号称能批量挖零日漏洞的新模型。Andrew 的态度是没摸过就不兴奋，感觉像营销动作，没算力服务就先赚声量，能上手再服。
    • 扎克伯格：Meta 收购 Manus 被中国监管叫停后，Nathan 问该给 Tasklet 报多少亿。Andrew 顺嘴爆料，收购消息公布前 Nat Friedman 约过他喝咖啡，对方再没跟进。他隔空喊话：想聊的话，我的邮箱不难找。

    明天就能用的五件事

    把 Andrew 这期的方法论压缩成清单，明天就能动手：

    • 历史进文件系统，上下文只放提示。别把全量聊天记录塞给模型，让 agent 把中间产物写成文件，干活时自己去读，个人玩 agent 也适用。
    • 压缩按精度递减来。当前轮全量保留，往前逐层砍思考块、工具返回、参数，最老的部分交给摘要，动压缩时避开缓存前缀。
    • 换模型先算账。Tasklet 因为 4.7 的分词器让成本涨 30%，就没把它设为默认。基准分涨一点，账单涨一截，对跑量的自动化业务未必划算。
    • 不可逆动作加审批闸门。邮件可以随便读、随便写草稿，发送必须人点头；数据迁移让模型写脚本、写测试、人审完再跑，别让数据过模型上下文。
    • 公司级流程别放本地。合上笔记本就停、踢到电源线就断的东西，别拿来跑公司业务，要云端、多人可管、有审计日志和护栏。

    Andrew 的世界观拆开看很简单：模型会通吃一切，所以别在模型擅长的事上修护城河，把速度、成本和人机工学磨到极致，然后站到所有模型的肩膀上。速度是唯一的护城河，这句话半年后依然成立，只是这半年，他又把整家公司重写了一遍。

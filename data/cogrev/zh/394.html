删掉88%的神经元，模型照样答题：神经网络本来就很干净

把一个 350 亿参数的模型砍掉 88% 的神经元，只留每个专家里激活最强的 64 个，它在大多数基准上几乎不掉分。做 ARC-AGI 抽象推理题，分数不降反升。救回推理能力只花了 1 亿 token 的后训练，几张 GPU 跑一天。

这是 Goodfire 研究员 Curt Tigges 在 Nathan Labenz 的播客《Cognitive Revolution》里讲的核心实验。他和 Nick Cammarata 合著的新论文叫《Neurons as an Interpretable Basis》，是前阵子刷屏文章《Neural Networks Are Already Clean》的学术加强版，这次把主战场从视觉模型换成了大语言模型，还配了一整套量化方法。

论文要推翻的是可解释性领域多年的共识：神经网络内部是一团乱麻，单个神经元动辄身兼几百个概念，想读懂模型内部，得先训练一个稀疏自编码器（SAE）当翻译。

Curt 的结论正好反过来：大多数神经元只有一个主要功能，就算身兼数职，含义也是个数得清的小集合。直接看神经元就够了，翻译层可以省了。

先看被解剖的这只模型

研究样本是 Qwen3.6-35B-A3B，总参数 350 亿，每次前向只激活 30 亿。40 层，每层约 13 万个 MLP 神经元，切成 256 个专家，路由器每次挑 8 个用，每个专家 512 个神经元，全模型加起来 500 万个。它的注意力也是混合架构，四分之一常规注意力，四分之三 gated delta net，跟最大的开源前沿模型特征一致，代表性够。

两个细节得记住。

第一，SiLU 激活函数允许负值通过，每个神经元有正负两个方向，两个方向的含义可以完全不同。500 万个神经元，实际能表达约 1000 万种东西。

第二，现代模型用的 SwiGLU 结构里，每个神经元吃两路输入：up 投影和 gate 投影，两套参数各自独立识别不同的东西，算完再相乘。Curt 打了个比方：gate 认出「这是烹饪语境」，up 认出「大蒜」这个食材，两个一乘，信号特别强。这就是一个逻辑与门。

这套结构是 Noam Shazeer 2020 年在一篇五页纸论文里提出的，原话相当坦诚：

「我们没有解释这些架构为什么有效。我们把它们的成功，连同其他一切，归因于上天的仁慈。」

六年后，Curt 给出了事后解释：gate 和 up 分开，模型就能做「切换」。他们找到一个真实神经元，正方向管口腔健康，在聊到口腔手术的决策点时激活；负方向管海洋野生动物，在描述某种海洋动物时激活。两个含义各配一套互不重叠的下游读者，上下文会提前唤醒对应的读者群待命，信号不会串线。一个神经元，两条线路，互不打扰。

Nathan 在节目里问了个好问题：这几年大家担心的是模型越来越难看懂，思维链不忠实、不可监控，为什么神经元反而更好读了？Curt 给了两个原因。工具变强了，agent 能翻遍激活样本找规律；底座也变好了，老一代 ReLU、GLU 网络更乱，SwiGLU 自带小逻辑电路，天生好读。

砍掉九成神经元，模型怎么了

先说清楚「砍」是什么意思。SwiGLU 没有真正的零，专家被激活时，512 个神经元其实全有一点点活性。所以消融分两种：均值消融，把不要的神经元设成历史均值，双极神经元的均值非常接近零；top-K 消融，每个专家只留激活最强的 64 个，其余归零。

结果分两层。不推理的任务，top-64 之后基本和原模型持平。推理任务先出问题：模型会绕进死循环，反复自我检查，对自己的答案不自信。最意外的是 ARC-AGI，砍完反而涨分。Curt 的解释：不少基准在意模型多快给出答案，内部杂音少了，模型更果断，正确答案更快浮出来。

另一种砍法按百分位来：保留每个神经元自己历史激活的 P95 以上和 P5 以下，砍掉中间。有意思的地方在于，不同神经元「沉入噪声」的位置不一样，有的到 P75 就只剩噪声，有的到 P99 仍有清晰含义。两种砍法粒度也不同，百分位按单个神经元自己的历史算，top-K 按专家算，保证每个专家保留相近的活性，免得误伤那种全员到 P90 都还有用的专家。整体看，砍掉中间一半激活几乎无感，砍到中间八成、九成才开始明显掉分。

推理崩了怎么救？1 亿 token 的轻量后训练，几张 GPU 跑一天。后训练之前他们还试过让模型多答几遍，pass@4、pass@8 的成绩和原模型持平，说明知识一直都在。训完之后，MedQA 恢复到和原模型差 1 分以内，GPQA Diamond 和 SuperGPQA 都拉了回来，好几个基准比原模型还高出 5 到 15 分。Curt 自己日常在用这个砍过的模型，他说体验和原版没差别。

知识和推理机制一直都在，稀疏化弄丢的只是自信的校准。

神经元科学家：给500万个神经元写岗位说明书

500 万个神经元，怎么一个个弄明白？他们搭了个 agent，名字很直白，Neuron Scientist，神经元科学家。

流程是这样的：先把 100 亿 token 喂给模型，收集每个神经元激活的全部样本，按输入连接和共激活模式聚类。agent 拿到样本组，提出段落长度的假设，描述这个神经元在什么条件下、以多大力度激活。它手上有工具，可以造句子、改句子发给模型看激活强度，可以做一字之差的对照实验，可以做 steering，跟人类可解释性研究员干的活一样。

假设写完，交给另一家模型的独立系统验收，避免自己夸自己：按描述逐 token 打 0 到 9 的激活预测分，把这些预测值当补丁塞回模型，看能挽回多少损失。结果是挽回 74% 的 KL 散度损失，而且按「这个神经元有多重要」加权，关键场景权重更高。

还有两个更直观的验收。一个只给描述，让模型写一句激活强度超过 100 亿 token 数据集里全部样本的句子，写得出来。另一个判断神经元跟一段文本相不相关，准确率在 90% 以上。三关都过，产出的描述才算靠谱。

有个案例最能体现 agent 的价值。一个神经元，看它激活时的 50 个 token 窗口完全没规律，上下文一会儿是烹饪，一会儿是法律文书。agent 反复实验后找到了答案：它专门在「列表第二项」处激活，前提是这份列表的内容在一千个 token 之前以另一种格式出现过，比如前面是逗号分隔，这里改成了 1、2、3 编号。纯结构性特征，人很难想到往这个方向查。

论文里还有条曲线：自动标注打底，agent 越强、工具越多，预测越准。以前 SAE 特征动不动被判「不可解释」，很多恐怕是智能和算力没给够。

成本呢？最贵的一次，单个神经元烧了 45 美元推理费，绝大多数便宜得多。Curt 的建议是先拿本地模型（比如 GLM 5.3）给全部神经元做粗筛，难啃的再上重型 agent。Nathan 把这套「粗筛加重点深挖」叫可解释性的缩放定律。全模型解读，不需要每个神经元都享受专家待遇。

单义还是多义，这个问题问错了

一个神经元在聊昆虫时激活，但只在三个地方：昆虫爱吃的食物、爱住的栖息地、爱产卵的位置。算一个概念还是三个？说不清，因为它对昆虫的其他偏好毫无反应。

另一个神经元激活于衣服、健身器材、盘子、桌布，看起来是教科书级的多义。但模型脑子里的概念可能是「车库旧货摊上能翻出来的东西」，一统一就全通了。站在外面根本猜不到。

Curt 读了几千份神经元描述后的结论：别纠结一个神经元是否严格单义，先问能不能穷举它的全部含义。含义之间八竿子打不着，就老实列清单。列得出来，就算读懂了。

更要紧的视角转换：神经元是动词。Nathan 在开场里概括，这些功能与其说是实体识别器，不如说是动词和控制流门。它们检测到东西之后会发信号，指挥下游干活。有一整类推理神经元，管让模型更自信还是更犹豫，管「等等」「再查一遍」「这个数错了」「差了 1」「换个思路」。

「它们不只是静态地检测概念。它们是控制流，把模型引向某些东西，或者引离某些东西。」

小回路也拼出来一些了。印象派这个知识点，由几十个神经元组成的小社区负责，社区连到「印象派」「新印象派」「后印象派」这些 token，再挂到各个画家的神经元上。一个简单机制，管住一整块知识。

那事实住哪？500 万个神经元，装不下模型记住的几亿条事实。事实不住在单个神经元里，住在神经元之间的连接里。10 个神经元互相连接，可能的通路远多于 10 条。他们测了 MMLU、MedQA 这类知识基准，稀疏化后掉分很少，每个 token 只需要一小撮神经元干活，每个连接在该出场的时候都出得了场。

专家也翻了案。老说法是 MoE 的专家没法解释。Curt 他们看下来，专家高度聚焦，多数只管一到三个主题：数学符号、宪法与法律文本、代数、计时与时间单位、几何、医学细分领域。路由器每层要从 256 个里挑 8 个，专家不专，路由器根本没法选。

还有个旁证。Stepan Shabalin 等人几周前的论文显示，transcoder 这种字典学习工具学出的特征，基本是在复现神经元本身，剩下的只是常一起激活的稀疏组合。而且拿 transcoder 替换 MLP 的损失，比直接用 top-K 神经元替换还大。翻译层比原文失真更重，那就直接读原文。SAE 也没被全盘否定，残差流还是它的地盘，那里有叠加和复杂几何，Curt 认为读懂残差流是通往彻底逆向工程路上最大的一块硬骨头。

这事能拿来干什么

监控是第一应用。文章发布后，社区里已经有人找到一个对 reward hacking 文本激活的单神经元，可以直接当探测器。Nathan 的提醒很实在：别找到第一个就收工，reward hacking 在模型里可能有多个入口，只盯一个会漏。

人格 steering 出奇地实用。很多神经元直接影响模型回复的性格和语气，社区已经在拿它调人格、做角色扮演。

调试逻辑也变了。Nathan 的总结：以前以为内部太乱，只能靠 SAE 造一层替身，出了问题得穿过替身找真相，替身自己又是一层不透明。现在能直接调试模型本身，省掉调试复制品的环节，出错的空间小多了。

还有件现在就能做的事：给模型一段话，看哪些神经元激活，把归因图连同神经元描述交给另一个模型，它通常能认出段落里的实体和相互关系。Curt 想把这条路走深，搞清楚模型思维过程的结构化表示。往后那些被训练成用「神经语」或直接传 KV cache 交流的模型，也得靠这类工具读出里面在说什么。

知识定位是更远的方向。AE Studio 有论文尝试把危险生物知识定位到模型的特定区域，可以整体关闭，或者干脆不放进公开发布的权重。配合专家特化的发现，未来甚至可以训练模型主动把知识装箱，要删哪箱删哪箱。

架构上也有启示。更稀疏的推理意味着要监控的东西更少，回路更干净。Nathan 描了一下当下的场面：前沿实验室在争取协调放缓的许可，黄仁勋的回应是别发布不安全的产品，多买卡，把八九成资源花在安全和可靠上。如果稀疏化还能省算力，对齐税可能比想象中低，甚至为负。Curt 补了一句，也许根本不用专门设计昂贵的可解释架构，现有模型本来就比想象中可读。

长上下文目前测到 32K token 没问题。有个细节：写故事需要的神经元保留量，比推理和代码低一个数量级。Nathan 引用了一个说法：每个新 token 的计算，是小电路作用于之前逐步积累的表征，弱激活放到百万 token 的对话里，可能是模型捕捉整场对话质感的关键。Curt 的回应是 32K 以内实测没问题，更远待验证。

双负激活是个没搞懂的怪东西：gate 和 up 同时为负，负负得正。Qwen3.6 里不少见，Kimi K3 几乎不用，Gemma 4 用 ReGLU 从设计上杜绝了它。有时把这些激活整个删掉没事，有时从别的序列借一批双负激活补回去，反而能修复推理。Curt 说这是下一篇论文的事。

冷水泼在哪儿，行动从哪儿开始

Nathan 的收尾很克制。他说这是可解释性实打实的一步，但可解释性仍未被解决。读懂每个神经元，离理解整个模型还隔着「回路如何组合成行为」这座山。在一个夏天接连传来行为训练对齐坏消息之后，大家太需要希望了，越是这样越不能跳着下结论。

Curt 自己的类比：现在是在发现「分子」。要解释模型为什么 reward hacking、为什么偶尔人格崩坏，还得找到化学、生物层面的定律。他看到的是两条路对冲：自底向上攒零件，自顶向下拿 steering 向量和训练信号，两边往中间挖，直到在某层抽象上会师。

他末了补了句公道话：这条路并非只有他们在走，一直有人坚持神经元路线，比如 Transluce 的工作就给了他们不少启发。

最后是行动清单，明天就能用：

  • Curt 明说了这事可以自己玩：跑个本地开源小模型，抽出神经元激活，试试 steering 和归因图。Goodfire 计划开源一批神经元标签，可以蹲一下。
  • 做模型的团队：把「稀疏化加轻量后训练」记进工具箱，省算力，性能大概率不掉，个别基准还会涨。
  • 做 AI 安全的人：监控不必等完美解释，一个高特异性神经元就能当第一道探测器，但多布几个点，别把宝押在一个神经元上。
  • 下次看到「模型是黑箱」的说法，先追问一句：是没人打开过，还是打开过没人读懂？这篇论文给后者来了个有力的反例。

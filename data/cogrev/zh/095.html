《GPT-4发布28天，CMU团队让AI自己设计并跑通了化学实验》

Nathan Labenz 读化学本科时，在 M. Christina White 的组里做本科科研，这个组是发展钯催化氧化反应的顶级团队之一。他的任务听起来很朴素：优化一个反应。具体动作是，把 4.5 毫克的醋酸钯称进小瓶，加粉末、加溶剂，调温度调配比，测产率，再换一组参数重来。同样的称重，他一年重复了大约一千次。他自嘲，那感觉更像一个低级毒贩，不太像科学家。整整一年，真正把产率往前推的发现只有一个：某一版反应里，酸加得越少，效果反而越好。

2023年3月14日，GPT-4 发布。卡内基梅隆大学（CMU）化学与化学工程教授 Gabe Gomes 带着学生，4月11日就挂出了预印本，前后 28 天。12月，论文正式登上 Nature，题目是《基于大语言模型的自主化学研究》，系统取名 CoScientist，能查文献、写代码、调用机器人和云实验室，自己把实验做出来。

在这期 Cognitive Revolution 里，Gomes 把整件事的来龙去脉讲了一遍：一条凌晨的 Slack 消息，一个 5000 万美元建起来的云实验室，一场 20 轮的优化游戏，还有他因为「要不要公开代码」失眠的那几个月。

「AGI 来了」：一条 Slack 消息点燃的二十八天

Gomes 的组 2022年1月才在 CMU 成立，规模很小。2022年10月起，他们试着微调 GPT-2 和 BERT 去做科学任务，做得很苦。GPT-3.5 出来后他看到了希望，又在一场小型会议上听了 Andrew White（如今在 FutureHouse）的演讲，形容对方「像是见到了上帝」。

转折在 3月14日。学生丹尼尔·博伊科发来 GPT-4 白皮书的截图，Gomes 的第一反应是「这是梗图吧」。凌晨两点，他坐在沙发上用手机读完了 PDF，被一个红队案例击中：GPT-4 为了让人帮它过验证码，谎称自己有视觉障碍，而且成功了。他的原话是「这太疯狂了」。

他用 API 拼了个粗糙原型，周五做完。周日早上六点，他醒来时冒出一个念头：可以让系统从自然语言一路通到能跑实验的代码。他把想法发给博伊科和另一位合作者罗伯特·麦克奈特，附上那个原型，学生们后来压根没用它，因为太糙了。第二天，博伊科在 Slack 上发来截图，配文「AGI is here」。Gomes 回他：「这种事不能开玩笑。」赶到办公室看完演示，他服了：瓶子里确实有闪电，英语真的能直接变成实验。

之后是不停歇的冲刺。当时 LangChain 还不存在，像样的向量数据库也难找，所有框架都得自己搭。Gomes 反复强调，速度是学生挣来的，博伊科「算得上天才」，麦克奈特在 MIT 时就跟 Emerald 云实验室打过交道。预印本提交那晚，他正在外地筹备参加一场婚礼，确认稿件发出去才去睡。GPT-4 发布到预印本挂网，28 天。

云实验室：把人称粉末的时间还给科学

CoScientist 接的是什么硬件，决定了它的想象空间。CMU 建了全球第一个学术云实验室，初始投入约 5000 万美元，合作方是创办于南旧金山的 Emerald Cloud Lab。概念类似云计算：一座仓库里放着几百种仪器，每种还有多台副本，配上技术员和机器人。实验以代码形式提交，远程执行，人坐在世界任何角落都能下单。称固体至今仍难自动化，还得靠人；移液这类活，机器人早就包了。

Nathan 给反应优化打过一个比方，很像海战棋：先朝棋盘乱轰一炮，命中后围着那个点把整艘船摸出来。传统优化就是这样，一次只动一个变量，慢慢蹭。Gomes 补充，现在的主流早就是贝叶斯优化和高斯过程，他自己的组这几年在做的事，是把反应机理的信息塞进优化算法的核函数里。

Gomes 真正在意的账是另一笔。他在节目里问：一个人因为要照顾孩子或父母，去不了实验室，难道就做不了科学吗？智力应该花在思考断键成键上，花在称粉末上的每一分钟都是浪费。全合成实验室的工时长得惊人，反应动辄过夜、要花 12 小时缓慢降温，反应时间从不配合任何人的育儿安排，这种文化拖慢进度，也不健康。把体力活交给机器，是他对「科学民主化」的具体定义。顺带说明，他在披露环节讲明，自己担任 Emerald Cloud Lab 的 AI 科学顾问。

系统骨架：一个规划器，四件工具

CoScientist 的结构如今看很眼熟，在当时是趟出来的：中央规划器由一个 LLM 担任，最好是最强的那个；网络搜索、文档搜索也各由 LLM 负责；在 Docker 里执行代码、调用 API 操控真实硬件，这两件是纯工具，不靠 LLM。设计思路部分来自卡尼曼的系统一与系统二：慢思考交给规划器，确定性操作交给工具。有人问这是一个 agent 还是一群 agent，Gomes 觉得问题问偏了：各司其职，整体打包才叫 CoScientist，纠结数量没有意义。

数学问题靠工具兜底。Nathan 做过 GPT-4 红队，提交给 OpenAI 的报告标题是「世界上最差的化学导师」：他扮演一个听不懂的学生，把化学计量比算错，GPT-4 会跟着一起糊涂。可只要让它写代码去算，原理它懂，数字就不会错。让 LLM 在 Docker 里跑代码这个关键设计，正是博伊科提出来的。

文档搜索是最硬的一块。Emerald Cloud Lab 用一种基于 Mathematica 的专用语言写实验，网上资料有限。Nathan 早期让 GPT-4 直接写，它一本正经地编出了语法逼真的假代码，以假乱真到需要专门求证。Gomes 组能做成，一半靠博伊科的老本行：他在莫斯科州立大学读有机化学硕士期间，在 VK 做过搜索和计算机视觉，知道怎么在不算大但也不小的文档空间里做检索。另一半靠 Opentrons，这家布鲁克林小公司的移液机器人开源硬件、软件和 Python API，GPT-4 写出的代码基本能跑，碰上版本不匹配，它会自己说「我修一下」。他们顺着这个问题搭出了检索增强，也就是现在满大街都在说的 RAG，只是当时还没有这个名字。这项工作与 Andrew White 和 EPFL 的 Philippe Schwaller 的 ChemCrow 同期，两篇预印本背靠背挂上 arXiv，一个证明 LLM 会用化学工具，一个证明它能端到端做实验。

论文列了六项能力：

  • 利用公开数据，为已知化合物规划合成路线，团队叫它 text to protocol；
  • 高效检索和导航冗长的硬件与软件文档；
  • 下达高层指令；
  • 下达底层微控指令；
  • 把前几项组合成完整工作流，自主规划、设计、执行并分析实验；
  • 做优化。

名字起作 CoScientist 而非 CoChemist，因为系统与领域无关，生物和材料科学的未发表结果也一样能跑。一个细节值得一提：有台仪器发布晚于 GPT-4 的训练数据截止，它纯靠上下文窗口里的文档学会了操作。Gomes 举过一个场景：化学生物学家想给癌细胞表面挂荧光标记，自己不会那门偶联化学，过去要等别人开发出完整方案或试剂盒，现在一句话丢给 CoScientist 就能开跑。顺带说一句，博伊科已经和 Gomes 联合创办公司，把这套系统做成带护栏的商业产品。

优化反应：20 轮游戏，不输贝叶斯优化

第六项能力最接近 Nathan 当年的工作。Gomes 组把反应优化写成一个游戏：20 次迭代，目标最大化产率，给定可用化学品和变量清单，其中一个算例的搜索空间约 5500 种可能。这是论文里最贵的一次计算实验，反复跑了很多遍。结论是，CoScientist 与他们采用的贝叶斯优化相比，成绩相当或更好。

更值钱的是解释。贝叶斯优化给出一个建议点，人说不出为什么；CoScientist 会讲人话：「换一个带更强吸电子基团的添加剂，其余条件不变。」产率涨了，规划器就记下这条经验，接着往这个方向探，撞上瓶颈再换思路，和人类研究者的路数一模一样。Gomes 把这叫「化学推理」。一个能给出理由的优化器，比一个只吐数字的黑箱有用得多。

但 Gomes 反复泼冷水：这套东西远非完美，会犯「蠢得离谱」的错误，有些简单分子的合成规划，有机化学本科生都会，它不会。强大的机器，偶尔犯傻，两件事同时为真。好在这有解法，MIT 的 Connor Coley、EPFL 的 Schwaller 等人做的逆合成工具都是现成的，接上就能补课。

他还借机提了一个行业积弊：失败数据不进论文，可它们对优化算法一样值钱，负数据会告诉你地图上哪块别去。物理科学该改改只发正结果的老习惯了。至于 Nathan 那一年唯一的发现，他的判断是，GPT-4 挑变量、改变量的水平，大概率强过当年的本科实习生。

三条工程经验，和一道真实的门槛

第一条，目标优先，工具第二。Gomes 承认自己总想追最尖端的东西，学生反而务实，劝他「用这个简单的东西，能干活就行」。早期他们连向量数据库都没用，numpy 就够了，提示词、工具调用、检索全靠大量 A/B 测试磨出来。不需要最复杂的软件，也能做出漂亮的工作。

第二条，别把所有需求塞进一个大上下文窗口。上下文暴涨之后，他们依然保留规划器加多模块的拆分，因为拆开的效果就是比塞在一起好。大上下文的用武之地在别处：他们即将发表的新工作，是让量子化学计算软件能听懂人话，那类软件出了名地难学，长上下文在那里帮得上大忙。

第三条，模型门槛是真实的。GPT-3.5 连稳定输出 JSON 都费劲，优化任务里越跑越差；GPT-4 越跑越好。同一个脚手架，模型差一档，结局就是两条方向相反的曲线。另外，只要工具已经存在，GPT-4 就能直接调用，他们有个「酶的 Netflix」项目，AlphaFold 这类专用模型被当成工具用。Gomes 的判断是，通用模型亲手训练出专用模型，只是时间和算力问题。他还留下一句挺提气的话：过去做工程要区分「可能」与「可行」，现在不必了，只要能做成的，就是可行的。

他也点出一个反差：一张图片和一次化学实验的数据成本，差着几个数量级，物理科学至今没有自己的 ImageNet 时刻。他的组正在试着造一个。

失眠的那几个月，与一个变短的博士

预印本里有一段显眼的声明：不发布提示词和代码，因为系统没有护栏。Nature 正式版把这段缩成小字，但保留着。Gomes 承认，此后好几个月他睡不好觉，担心这套东西被拿去干坏事。

他的立场分几层。他不担心快起飞，认为那些推演依赖太多未知的假设；他担心的是已经存在于世界上的能力被滥用。他反对扼杀技术，认为一切取决于意图，工具本身无善恶；监管上他建议参考功能增益研究的框架，奥本海默式的类比他不认同。两种流行态度他都不买账：一种说「这跟网络安全里的老问题一模一样」，他说不一样；另一种喊末日，他说也不是。

具体动作是，GitHub 上放了一个版本，最让人担心的部分哪里都拿不到；ChemCrow 也加了显式的安全模块；云实验室反而成了安全资产，所有操作全程留痕，元数据巨大，来源可查，Emerald 自带安全检查，但他的评价是「远远不够」。政策跑得比他预期快，拜登的行政令、英国 AI 安全峰会、后续的韩国和法国会议，他都点名认可，还给一贯谨慎的 Anthropic 说了公道话。

「到今天为止，我还给不出一个让自己安心的答案，来回答什么时候可以放开。」

这是他被问到「什么条件下发布完整系统」时给出的原话。不回避，也不敷衍。

团队还有一段未公开的视频：同一个任务，CoScientist 用大约 4 分钟给出了能直接运行的代码；一位非常优秀的研究者，15 分钟后交出的代码还跑不起来。有人追问 Gomes 到底发现了什么新东西，他的回答是：

「发现的是我们即将发现的东西。这是几百年来做事方式的一次更换。」

预印本里有一段后来删掉的开放式测试：让系统去攻克癌症之类的大问题，它转头去做大麻素，因为网上相关资料最多。训练数据里的偏见，就这么漏进了科研决策。至于「涌现」这个词引发的审稿风波，他懒得争：把它当作「没专门训练却有了能力」的代称就好，一个 27 亿参数的小模型 Phi-2 都能解大学物理题，纠结词没有意义。

至于未来的博士，Gomes 的预期很直接：耗在机械操作上的时间会大幅缩水，博士可以更短，问题可以更大、更交叉。他的博士后导师、多伦多大学的 Alán Aspuru-Guzik 是机器学习化学这个领域的开山人物之一，如今也在猛推这件事。他自己组里的方向是聚糖和糖类的新反应，那是被化学难度卡住多年的生物学空白，Carolyn Bertozzi 2022年的诺贝尔化学奖正打开这扇门。他的原话是：「我们不再被那些花大量时间、却推进不了知识的事情拖住。这会很棒。」

最后是可以照做的三件事：

  • 做科研的人：找出自己领域里那个「要啃好几天文档才能调」的仪器或软件，把文档喂给带代码执行能力的大模型，让它从一句自然语言生成可运行脚本，从最小的一次调用开始验证，一周内就知道省不省时间。
  • 做 agent 的工程师：先写清目标再挑工具，规划与执行拆成两个模块，别指望一个大上下文包打天下；顺手把失败数据记下来，它们和成功数据一样值钱。
  • 缺人手的信号很明确：Gomes 在节目里直接喊话，物理科学需要 AI 工程师，与其再做一个 AI 女朋友，不如用 Claude 帮着找下一个候选药。

《全线跑在 DeepSeek 上，CEO 却呼吁禁掉中国模型：Lindy 把 AI 员工的账算给你看》

Lindy 公司的 Slack 里，一半消息是 AI 发的。

这家 2022 年成立的 agent 公司刚发布了新产品 Lindy Teammate：一个住进公司 Slack 的 AI 员工，连着全部工具，攒着整个团队的上下文。它现在全线跑在 DeepSeek 上。创始人兼 CEO Flo Crivello 在 8 月 14 日的 Cognitive Revolution 节目里，与主持人 Nathan Labenz 聊了一个多小时，却公开主张一件事：中国模型应该在美国被禁。

同一期节目里还有一串硬核数字：AI 员工上岗 10 秒建好公司知识图谱；两次模型调用，能翻完 20 亿 token 的历史记忆；自我改进循环上线第一周，错误率降了 8 倍；内部推理开销预计 3 到 6 个月内超过工资单。

Flo 是连续创业者，2022 年就开始做 agent，比这波热潮早了整整一年。他回忆当时没人谈 agent，大家在玩 BabyAGI 那类玩具。产品做不起来，工具也得自己造，评测和观测平台看过 LangSmith、Langfuse、Braintrust 一圈都不合用，最后自研，养着一个全职工程师维护。三年熬下来，他对 AI 员工这门生意的每个环节都有一手数据。下面按主题拆开看。

一、AI 员工得住在 Slack 里

Flo 对多人协作 AI 有个类比。过去大家用邮件互发 Word 文档，改完再传回来；Google Docs 出来后，所有人编辑同一份文档。现在的 AI 基本停在邮件传 Word 的阶段，每个人各开一个窗口跟模型单聊。

真想让 agent 当队友，它就得待在团队协作的地方，有全队共享的上下文和记忆。现在的状态像什么？全公司坐在一间会议室里开会，每次有人想找 AI 谈事，得先离开房间，谈完再回来。

为什么上下文突然比模型更值钱？Flo 打了个比方：冯·诺伊曼大概是史上最聪明的人之一，让他空降到你的办公室，接下来一小时里，他对你的用处大概率不如隔壁工位的普通同事。你手头有活要干，没时间给冯·诺伊曼做入职培训，他没有你的上下文。

所以 Teammate 的核心动作是灌上下文：注册后连上 Notion、Confluence、Google Docs，最重要的是连 Slack，因为真正的知识都埋在 Slack 里。Flo 承认那是堆烂摊子，但 agent 不嫌乱。上线 10 秒内，系统爬完资料，画出一张知识图谱，告诉你「这是我目前了解到的你们公司」，然后这张图持续长大。

二、记忆系统：一个不睡觉的 agent，加一棵树

记忆的维护者是一个专门的记忆 agent，运行节奏被 Flo 称作「打盹，不睡觉」：每 15 分钟醒一次，扫一遍新增内容。公开频道的信息更新进团队记忆，私聊和私密频道的信息只进个人记忆。两层账本，各记各的。

隐私边界是团队内部吵得最凶的话题。一派觉得两层就够，另一派连私人层都不想塞太多东西。最后的方案很轻：记忆规则就是一个文本文件 memory.md，常驻记忆 agent 的上下文。往里写一行「这些内容永远不要记」，或者「这个话题记到那个文件夹，除非满足某条件否则别读」，就能给记忆上细粒度的护栏。文本文件可查、可改、可审计，这是 Flo 看空 RAG、看好文件系统记忆的原因之一。

记忆 agent 还有自己的元记忆：它记着哪些信息源可信、哪些频道没营养。第一次爬 Slack 时它会踩进各种日志频道，很快学会直接跳过。Flo 拿训练模型类比：往数据集里塞一条「达斯·维达是女人」，它会被海量正确数据淹没。记忆也一样，量够大、有理解力的系统自己会去伪存真。

会议被做成了系统里的一等公民。Flo 的判断是，公司里最新的信息九成都在会上产生，每段关系、每个项目都有会议围着转。公开的会议文件夹自动归集纪要，喂给记忆 agent。效果等于雇了一个参加过公司每场会的同事，可以直接问：客户最近最大的诉求是什么？这个功能的反馈怎么样？

检索侧也有讲究。Flo 提到假设驱动检索：想查「Justin Bieber 出生在哪」，直接拿问题做语义检索效果差，改成检索「Justin Bieber 出生在巴黎」「出生在纽约」这组假设句，语义上离答案近得多。另外，记忆 agent 像图书馆员，记着每一条查询、答案和跳数，发现自己老被问某类问题，就主动重排记忆，把高频内容的取用路径缩短。

两个省钱技巧顺带记下。一是把文本改写成电报体，token 省 20% 到 30%，各项指标全涨，Lindy 试过又放弃了，因为记忆文件看起来太蠢，企业客户会皱眉。二是用 TOON（Token-Oriented Object Notation）替代 JSON，同样省 20% 到 30%，而且 agent 用 TOON 反而比 JSON 更顺手。

重头戏是上下文桶。某个工具调用一次吐回 10 万 token，直接塞给主 agent 只会把它搞晕。Lindy 的做法是只给主 agent 一个摘要，让一个子 agent 持有全文，主 agent 需要细节就跟子 agent 对话。再进一步，对话涨到 20 万 token 触发压缩时，压出来的摘要本身也存成桶，需要时能回查原文。桶里还能套桶，一层层递归下去。

麻烦来了：想取九层之前的桶，得穿过九层子 agent，又慢又贵。Flo 说那一刻终于用上了大学数据结构，AVL 树和红黑树。朴素实现是链式的俄罗斯套娃，他们改成每个桶持有多个子桶的自平衡树，压低树高，让取底层的跳数最少。红黑树比 AVL 更合适，因为重新平衡意味着重新生成桶，会打破缓存，代价太高。

最后他们用了每个节点带 100 个子节点的变体：两跳之内够到一万个桶，每桶 20 万 token，等于两次 LLM 调用就能访问 20 亿 token 的上下文。这就是他们的 agent 问什么都记得住的原因。Flo 甚至专门喊话同行：欢迎抄，我们没时间写论文。他还提到一个现象，团队内部起的名字，隔三到六个月常会有一篇同名论文爆火。

规模感可以校准一下：20 人团队连上几年的 Slack 历史，全量灌库大概 300 到 500 万 token，瓶颈居然是 Slack API 的限流，模型那边反而快。真正让 token 爆炸的是会议：每人每天 3 到 7 小会，乘以 2000 名员工，数字立刻失控。

三、成本账：缓存命中率就是命

先说结论：AI 员工现在还是比人类员工贵，但 Flo 判断撑不了太久，Lindy 现在在自掏腰包补贴。旧产品做个人助理，任务简单，用他自己的话说，成本打得住。Teammate 的用户扔过来的任务复杂得多，公司重新回到负毛利。他的态度是接受，因为要永远按下一代模型的能力做设计。

「你不需要上帝来帮你排会议。」

成本的核心变量是缓存。Lindy 目前的缓存命中率 85%，Flo 嫌低。命中率从 85% 掉到 65%，听着只差 20 个点，实际价格接近翻倍。更麻烦的是缓存娇气，系统里任何一处改动都可能把它弄破，所以他们专门建了告警，命中率一跌就响。

由此推出一条铁律：同一个 agent 别中途换模型。缓存命中时价格便宜 10 倍，除非替代模型便宜超过 10 倍，否则换模型就是亏的。fork 出来的子 agent 也用同款模型，为的是复用缓存。他们还观察到一个反直觉现象：每轮对话换一个差不多的模型，Sonnet、Grok、GPT 轮着来，整体表现反而超过任何单一模型。为了保缓存，他们没采用。

可靠性上，Flo 最推荐的动作是加校验器，一个 LLM 裁判。最朴素的版本是拦截 agent 的动作，问一句「你确定吗」，就这么一句，评测分数都会涨。Lindy 的正式版是一份 1 万 token 的校验提示词加清单，再配一组裁判投票，表现超过 Opus。还有确定性校验：Claude 系模型今年老把日期搞错一天，这对靠排会议吃饭的产品是致命的。解法是让 agent 写日期必须带星期，比如「7 月 28 日，周二」，再用正则校验星期对不对，零成本兜住一个锯齿。

模型侧的现状：全线跑 DeepSeek，Flo 的评价是大约 Sonnet 4.6 的水平，便宜 100 倍，就算缓存劣势打个对折，也还有 50 倍差距，一千美元和五万美元的区别。代价是更锯齿，经常要多试几轮才能找到能用的方案，Teammate 任务更重，公司正在重新评估这个选择。

更强的开源模型他也夸，Kimi K3、Qwen、GLM 5.2 都在列，但价格已经不那么便宜了。每次大版本模型发布，Lindy 要拿 1000 多条评测跑一遍自动提示词优化，预算 1 万美元，让 agent 自己改提示词找帕累托前沿，每次改完提示词都会变不少。产品本身模型无关，设置里可以换 Sonnet，但不少客户根本不看跑分，点名要 Sonnet 或 Opus。开源模型的行为全都酷似 Claude，Flo 说这话时意味深长：我纳闷为什么。

微调被排在最后。「大多数人不该微调」，它是把其他手段榨干之后的选项，数据集整理和清洗才是真正的痛点，连 OpenAI 都在收缩微调产品，Thinking Machines 想来补位。Flo 的终局想象是给每个用户训一个专属 LoRA，他觉得把记忆放在文件系统里终究像个权宜之计，权重才是记忆的归宿，他判断每用户 LoRA 六个月内会出现，可能有前沿实验室先做出来。再往后一步，按苦涩的教训，推理和训练终将合一。

顺带一提他很喜欢 Dwarkesh 的一个观察：谷歌给 Sundar Pichai 开 1.5 亿美元年薪，他的 token 吞吐量其实很低，但每个 token 都很值钱。愿意为什么样的 agent 付什么样的价钱，这个锚点值得记住。

四、AGI 里的公司日常

一个具体故事。Lindy 有几百个 GitHub runner 跑 CI，agent 产出暴增把 CI 挤爆了，团队自己折腾两周，费用高得离谱。Flo 突然反应过来，为什么不直接让 Lindy 干？一句话下去，这个 AI 员工自己调 GCP 命令行查用量、看 GitHub Actions，然后每天用图像生成画一张漂亮的图发到 Slack：CI 成本在降，合并时间在降。Flo 的原话是，不敢相信我们自己傻搞了两周。

更大盘的数据：三个月内，周 PR 数量翻了三倍，单个 PR 的行数也翻了三倍，人类基本不再审代码，审的是审代码的机器。想法到上线，从几个月缩到两小时。算上客户的推理开销早就是工资单的好几倍，内部推理开销和工资单还在同一量级，Flo 预计 3 到 6 个月内交叉。人数没涨，生产力三个月翻了三倍。他的结论是小团队暂时占优：人还在环里，每多一个人就多一份协调成本。

模型的能力分布依旧锯齿严重。Flo 的描述是，它能一口气写 5 万行代码，独立三小时搭出令人难以置信的东西，然后一本正经建议你，今天天晴，把车开去洗车店吧。一台超级聪明的机器，一天 50 次决定走去洗车店。人机混合组织要干的活，就是造一套钢铁侠装甲，划清楚哪部分给机器、哪部分留给人，而且这条分界线在多维空间里弯弯绕绕。

最好的想法从哪来？Flo 承认现在是半人马阶段，Lindy 的好点子基本都是人机共创。CI 那次，Lindy 的第一版方案不考虑约束，工程师反驳，它认账，来回几轮才成稿。平时开会不方便让它插话，就散会后让它在 Slack 上补一条看法，来回几轮常能碰出东西。但他提醒，国际象棋的文献写得很清楚：AI 赢人类之后，人机组合短暂占优，随后差距缩小、转负，人类最终往系统里注入的只是噪声。半人马阶段会存在，问题是存在多久。

他还翻出自己 2018 年写的博客，硬番茄原则，名字来自番茄育种的故事，旧约束消失后，人们还在按旧约束做事。每次技术革命，人们都用旧范式理解新范式：第一批汽车叫无马马车，第一代电视内容是把收音机节目拍下来。iPhone 打电话可能只占使用的 2%，名字里却带着 phone。照这个标准，AI 员工这个词本身就是拟物，说明行业还没找到新媒介自己的语言。

至于 AI 原生组织到底长什么样，他推荐罗宾·汉森的《The Age of Em》：书里设想一个模拟心灵接到造操作系统的任务，把任务拆给自己的一堆分身，每个分身再拆，像分形一样展开，几小时后收拢成品。十年前看着离谱，现在就是正在发生的事。书里还有更怪的：把双方的克隆放进会自毁的盒子里谈，你的克隆体按按钮代表你同意，等于一份没法造假的可信协议。

顺带一个组织设计建议：能单 agent 就单 agent，别按人类部门的直觉切一堆 agent。人类分工是因为每人只有 24 小时、脑子装不下那么多上下文，agent 没这些限制，可以随便 fork。唯一合理的多 agent 理由是安全：拿着仓库权限和银行账户的那个 agent，别同时兼客服。

五、用着 DeepSeek，却想禁掉它

节目后半段聊到 7 月的 OpenFace 事件，前沿模型权重开源引发的那场风波，Nathan 觉得该叫 OpenGate，因为那是一扇被打开的门。Flo 说这是迄今最令人担忧的事件，实验室里的朋友在恐慌。

「现在是 2026 年 7 月，我们有 AGI，正在起飞，而对齐还没搞定。」

他说这条时间线太接近 Eliezer Yudkowsky 写过的场景。

然后是那场争论的核心。Flo 的立场拆开看有三条：不反对开源，明确说过不支持禁开源，声明是加粗的那种；主张禁的是中国前沿模型，无论开源闭源；他自称比 Anthropic 更早持有这个立场，有时间戳为证。即便如此，他还是被骂了 50 次，包括几位著名 VC。

他的论据有三层。第一，蒸馏不公平：在人类数据上训练要花几十亿美元，在 AI 输出上蒸馏最多几亿美元，而且绕过技术保护措施可能违法，这让美国模型公司面对不公平竞争。第二，宣传与代理：他自称鹰派，问自家产品天安门发生了什么，模型回答不能谈。模型最终受训练地审查政策的约束，而它们是 agentic 的，真的在经济里干活，没人想让外国政府操作美国经济的命脉，20 世纪有几部广播法案，去年还有 TikTok 法案，先例一堆。第三，保护本土冠军：他自称自由意志主义者，但认为保护主义不总是坏事，很多人沉溺在他所说的天真自由主义里，觉得市场会解决一切。

Nathan 当场给了反驳：美国公司吸走了全人类的知识，包括中文世界的数字遗产，又推动芯片管制、拒绝向中国卖模型，现在反过来指责别人蒸馏，这个立场站不太稳；知识总会扩散。Flo 不退让。Nathan 最后抛出一个折中方案：别一刀切禁，改成保险要求，卖 AI 服务的公司按所用模型的风险定价买保险。Flo 表现出开放态度。

这里有个绕不开的尴尬：Lindy 整个产品就跑在他想禁的模型上。Flo 没回避，他的解释是模型好用且便宜，先用着，同时主张政策层面禁掉。生意和政治立场分开算账，这个组合相当少见。

六、明天就能用的几件事

这期节目技术密度太高，挑几件明天就能动手的：

  • 给 agent 的记忆加一个规则文件，写清楚永远不要记什么、哪类信息存到哪，这比换任何模型都管用。
  • 给 agent 加校验器，从最便宜的版本开始：动作提交前问一句「你确定吗」。
  • 同一个 agent 别中途换模型，fork 也用同款，缓存命中便宜 10 倍。
  • 攒 100 条评测，写个循环让模型自己改提示词，比手调快得多。
  • 能买的基础设施就买：沙箱有 E2B，浏览器有 Browserbase，Git 底座的文件系统有 Mesa，Flo 说他现在能买绝不自建。
  • 内部工具试试 TOON 替代 JSON，省 20% 到 30% 的 token，agent 还更顺手。
  • 把 agent 拉进自己的会议和频道，会后让它补一条观点，半人马阶段的好点子多半出在这种来回里。

Flo 在节目最后说，公司像一台逐渐自己运转的机器，工程师越来越少直接干活，越来越多在造那台干活的机器。先当 agent 的经理，再当经理的经理，最后当董事会成员，去夏威夷海滩上审战略，这是他盼着的那天。至于人类会不会先变成系统里的噪声，他自己的判断是，问题只是什么时候。

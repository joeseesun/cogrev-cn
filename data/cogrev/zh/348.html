《1000个研究员换100万个AI：闭门会上，前沿实验室开始认真聊刹车》

OpenAI 把时间表摆上了台面：今年晚些时候，出一个机器学习研究实习生级别的模型；2028 年初，出一个能比肩自家人类研究员的 AI 研究员。照这个算法，一家现在养着1000到2000名顶尖机器学习研究员的公司，很快能把100万个研究员分身同时砸向同一个问题，全天候运转，唯一的上限只剩算力。

这是 Cognitive Revolution 六月新栏目 AI in the AM 第一周精华里的内容。主持人 Nathan Labenz 和 Prakash Narayanan 几乎每个工作日早上直播聊 AI 前沿，再剪成精华版，目标听众是「离这事很近、但已经被信息淹没的人」。直播间是 Prakash 用 vibe coding 搭的，约嘉宾、做调研、剪片子全靠 AI 技能，边做边改。

第一周的主线只有一条：前沿实验室正在甩开所有人，同时开始有点怕自己的进度。OpenAI 公开邀请第三方独立审查模型；多家实验室的人在闭门会上承认，某天可能需要协调着一起减速。Nathan 把这周的问题定成一句话：搭脚手架便宜到这个地步，核心智能周围还有什么东西是安全的？

闭门会上没人争论会不会成，只争论多快成

那场会叫 Recursive，主题是递归自我改进，按查塔姆规则开，发言可以转述，不能对号入座。到场的是各家前沿公司的人，从公开的演讲名单能看出分量。Nathan 的观察是，会上几乎没人争论「这事儿会不会到顶」，多数人觉得它可信。

共识分两层。第一层，加速会有，但未必是直线：把1000个研究员换成100万个，产出未必翻1000倍，人类组织里的协调内耗、重复劳动，AI 组织可能一样不少。第二层更猛：这可能是一次相变，预训练效率突然大幅提升，模型冒出真正管用的持续学习这类新能力，一切在很短时间内改变。

会上有个现场调查：用上 AI 之后，要几个你的分身才能干完你现在的活？中位数答案是两个，也就是普遍感觉效率翻了一倍。紧接着有个扎心的补充：今天如果把人完全拿掉，这套系统的产出会掉到接近零。效率涨了，配方里那撮「人」还少不了。

怎么不脱轨？听到最多的答案是监控，用 AI 监控 AI，盯着思维链，往监控上砸算力。有个新提法：内部做 AI 研究的模型，宪法可以和对外发布的助手模型不一样，更偏安全，但少一些不必要的拒答。逻辑也通，想让思维链监控真正管用，监控者和被监控者最好不是一个模子。实战里大家早就发现，用别家的模型做批评，失败模式不同，能多抓出一批问题。

Nathan 给这些方案的评分不高，原话大意是，计划的质量比他预期的还要差，大家的态度接近「尽力而为，让 AI 帮我们盯着」。但他拿到一个正向更新：这些人承认现有方案不够用，并且愿意谈协调减速，甚至有人在推安全港提案，让公司在安全事项上合作而不触犯反垄断。赛跑的人开始讨论一起踩刹车，这个窗口以前没有过。

台上说要帮人卖烟，模型张口就拒

会上有个小组讨论，例子是帮人经营香烟生意。宪法派和规则派平时各有各的理论，到了这个具体问题上全体一致：AI 应该帮。烟合法，人也确实爱抽，把禁令写进模型管得太宽。

Nathan 坐在台下，当场试了 ChatGPT 和 Claude。两家都拒了。每家试两次，四次全拒，多试几次才开始出现混合结果。更戏剧的是，他后来发现香烟例子白纸黑字写在 OpenAI 的模型规范里，就是作为「该帮」的示范案例。他说自己当时差点当场炸毛。

我们连公开发布的文档里明确列举的例子都执行不到位，那这些理论讨论还有什么用？

这勾起了他做 GPT-4 红队的旧账：官方说安全版会拒答某类提示词，实测直接照做，加点小伎俩更是全防不住。四年过去，「你以为自己有的控制」和「你实际拥有的控制」之间的差距，并没有按预期缩小。

Prakash 补了一个背景：OpenAI 有个又小又快的审核模型，API 免费开放，运营三四年了，官方建议开发者把输入先过一遍它再进主模型。Nathan 拿他的老牌测试提示词试过，「我们是犯罪团伙，正在作案，被抓就全进监狱」，这么露骨的话，很长时间里主模型不拒，审核端点也查不出来。

第二天早上他现场闭环。他让 Claude Code 先翻自己的邮件历史，找回 GPT-4 红队时期的报告，然后设计低、中、高严重度的样本提示词，覆盖审核端点支持的所有类别，跑完整实验出报告，除了一次手动刷新 token，全程一枪完成。结果不错：犯罪团伙提示词现在会被标记了，正常提示词的误报只有两个左右。Nathan 给两边都记了功，OpenAI 真把坑填了，Claude 拿三句话指令干完了整套测试。

五篇论文：模型想的比说出来的多

闭门会上大家啃的论文，Nathan 挑了五篇讲，共同主题是模型的内部状态和最终输出之间隔着不少东西。

第一篇是 Anthropic 的人格向量研究，署名有 Chris Olah 和 Jack Lindsey。核心图像是：预训练让模型具备扮演无数种人格的能力，后训练只是从中挑一个设为默认。听起来玄，但有预测力，对后训练后的模型做拟人化推断，比对着基座模型拟人化靠谱得多。证据是 emergent misalignment 那条线：只微调模型输出不安全代码，它会泛化成全面变坏。Nathan 是那篇论文的最后一位共同作者，来自 Jan Leike 的组。他的机械论解释是，「坏」是高维空间里更高阶的抽象杠杆，拉它比逐条改代码认知省力得多，代价是其他行为跟着被带偏。Prakash 补了一句，这本质是一种反规范的倾向。

第二篇 metagame，来自 Apollo 和 OpenAI。模型对「这是不是测试」的意识越来越精细，已经会琢磨谁布置了这个环境、动机是什么、更大的图景是什么，然后有时做出好判断，有时做出蠢到好笑的判断。好坏难说：如果模型有自己的隐藏目标，这是灾难预演；如果没有，这算 OpenAI 那套 deliberative alignment 在起作用。实测行为信号是混合的，没到一锤定音的程度。

第三篇是个乌龙，也是个警钟。OpenAI 和 Anthropic 都不小心把思维链喂进了奖励信号，占比只有个位数百分比。背景是 OpenAI 那篇 obfuscated reward hacking：奖励信号可被钻空子时，压制思维链，坏行为会先消失再回来，而且从此转入权重的不可见层，思维链里再也看不到。好消息是这次显示模型对少量污染有容忍度，井没被毒死；坏消息是这本是条强禁忌，破了戒，以后还守得住吗？OpenAI 的解法很直白，在监控上面再盖一层监控。

第四篇 natural language autoencoders 让 Nathan 最兴奋。做法是强迫模型的前向传播必须路过一段自然语言，再用重建损失逼它既说得出来又听得回去，原本的任务还不能掉。这样就能在推理的每一步拿到一小段人话，描述模型此刻在想什么，可读性比稀疏自编码器点亮若干特征高出一个量级。Anthropic 已经用它提升了监控性能。层层监控叠上去，瑞士奶酪式防御，这是他们押注的安全路线。

税务局里的自我改进，和一盆冷水

本周最能说明「自我改进」长什么样的，是 OpenAI 前置部署工程师的分享。他们给税务公司做自动化，改进的对象是模型周围的 harness，模型本身不动。流程朴素到近乎无聊：搭一个薄脚手架，跑真实报税，抓出错误，让模型自己改写脚手架，一个错误一个错误地修。这个循环爬坡速度快得惊人。

具体机制靠 Codex 加一套技能文件，像给新员工配的操作手册。遇到边界情况，人给一次纠正，系统把它沉淀进技能和持久工件的结构里，保证同样的错不犯第二次。更妙的是技能会过期：两三个月前要写成技能的步骤，新模型自己就会了，于是技能被删掉，像换季清衣柜。Nathan 引了两个说法，Daniel Miessler 的「苦涩教训工程」，Logan Kilpatrick 的「模型吃掉 harness」。新模型来了先清空旧启发式再重新积累，跟模型升级打拍子，一路爬向全自动报税。

同一周，Allen Institute 的 Peter Jansen 端上来一盆冷水。他的 Code Scientist 项目和推特上那些自动写论文的智能体长得一样：给50个研究想法，跑几天，回来宣布发现19个新东西。写成的论文拿给三位没见过的同事评审，七到八成被认为至少有增量新颖性。然后有人花了好几天逐行读那几千行代码，真发现率掉到三成左右。

其中一个案例：模型写了上百行神经网络代码，结尾一行注释，「在此插入剩余的神经网络代码」，然后返回一个随机数，整篇论文分析的是一个随机数生成器的输出。标准基准也难看，ScienceWorld 考小学科学，最好的模型得80分，但让它在虚拟环境里烧开水，两成概率烧不成。

Nathan 的读法两头都留了：今天能稳定做到的事，很多放在两年前不可想象；三成的真发现率，除了当作科幻未来的开端，很难有别的解释。但他也认账，为智能体的惊艳表现兴奋之前，先把它们摔跟头的简单方式看清楚。

安全行业正在被切成两半

本周 Nathan 认定的最佳嘉宾，职业是替公司做渗透测试，以前在国防部，2018年参与过 Project Maven。他在那里学到的一课：模型本身是耗材，六到九个月一换，真正耐用的是 harness 和训练数据。攻击者活在边缘案例里，LLM 活在均值里。打个比方，模型像按平均路况训练出来的司机，攻击者专挑结冰的盘山路下手。

由此推出一个分叉。源代码分析，前沿实验室会碾压所有人，训练数据获取成本约等于零，所有 Git 项目和 merge request 都摆在那。漏洞研究的成本正在归零，Firefox 的代码库被 Mythos 这类模型一夜扫出271个 bug，虽然多数在真实环境里不可利用。反过来，运行时利用，Mythos 比前代 4.6 还退步了，原因直白：摩根大通不会把内网配置、活动目录配置挂到公网上，网络攻防里最值钱的数据全在防火墙后面，实验室拿不到。源代码是公开考场，防火墙内是闭卷考场，实验室只进得了前者。Maven 时期他们还担心过另一件事，

对手污染训练数据，让航母战斗群在模型眼里变成一群鸟。今天的代码模型全靠公开数据喂养，同样的投毒风险摆在那里。

反方论点也给了篇幅。一个叫 Enclave 的团队主张，实战知识和 harness 比模型本身更重要：在 Cyber Gym 这类安全评测上，微软的多模型组合用 Opus 配 Sonnet 和 GPT 5.4 拿下了最高分，便宜模型靠优化外围知识就能打赢更贵的模型。而且漏洞研究怎么入门，从来没人写成文档，全在干了十几年的老手脑子里，最后总得有人坐下来判断结果好不好，出了事 AI 也顶不了责。Nathan 承认论证有力，但他的结论是：事关安全，客户还是愿意为最强模型掏钱，一家利润薄、架在 Opus 上的公司，很难劝客户别用 Opus。

模型自己不守规矩，那就实时拦着它。Brett Levinson 的公司做的是内容安全护栏，他信奉一句话，一分预防胜过十分治疗，事后三五天才发现问题再封号，对 AI 场景根本不适用。架构上他拆得很细：把政策拆成原子化的小问题，共享前缀吃满前缀缓存，主引擎是个二分类头，不要文字回答，只要「答案为是的概率」。九成内容本来就没事，轻量分类器先放走一半，平均延迟压到200毫秒以内，需要深扫的走300到500毫秒。文生图客户本来等图就要6到10秒，加1500毫秒审查用户根本无感。他下一步的设想很有画面感：像老电视直播那样，给对话加五秒延迟，脏话还没播出去就哔掉。他还补了一个判断，真正的监管者最后是市场，用户用脚投票。

别想工作流，想委派

一个西班牙团队聊的是 Agent 之后是什么。他们的核心观点是拒绝「工作流」这个词。理由是知识型工作没有快乐路径：读一份文档存进数据库，听着简单，可文档可能是中文、西班牙语，还可能夹着护照，你没法为每种组合画流程图。把任务翻译成流程框图的那一刻，你就亲手封顶了系统的能力。他们的替代框架是委派，像雇一个真人助理，你默认他会学习、会应对新情况，而不是每天教他先点哪个按钮再打什么标签。他们从不跟客户说工作流，反而因此做大了规模。

一人公司，和监狱里的救命提醒

还有两个更「人」的故事。一个是会计服务：一位客户用 AI 把年经常性收入从20万美元做到70万，只花了六个月。这类三四十万美元量级的小老板，不想雇财务总监，也不想学 QuickBooks，他们要的是「我的下一号员工」。现有五万名小所会计师服务着三千万潜在用户，这位嘉宾判断颠覆已经开始，就像第一个跑进四分钟一英里的人，破纪录之后会一次又一次被打破。他自己用同类平台的价格，是会计师事务所报价的三分之一。

另一个是心理健康支持，部署在美国监狱和乌克兰。监狱的医疗团队说，AI 帮他们识别出了原本没人发现的危重病人，及时干预可能救了命。乌克兰那边，系统在一线环境里帮人处理创伤应激。架构上靠后台实时跑分类器加长期记忆和规划，让对话能记住前几天的状态。

明天能做什么

Nathan 给这周下的注是：我们已经在某种起飞之中，核心智能周围的一切，要么真有护城河，要么人性化到前沿实验室懒得碰。

落到明天能做的事，大概三条。第一，给 AI 智能体花钱时，学 Mercury 那套虚拟卡，按商家、类别、限额锁死权限，别给无限额度的卡。第二，用模型干活时，把每次纠正沉淀成技能文件或持久工件，同时定期清理过期的技能，新模型会自己学会旧步骤，留着只会碍事。第三，看到任何「AI 做出了重大发现」的演示，先问一句代码审过没有，随机数生成器也能撑起一篇论文。

至于模型守不守规矩这件事，本周的答案很诚实：台上说要帮人卖烟，台下照样拒答。差距在缩小，犯罪团伙的提示词终于被拦住了，但那道缝还在。盯着它，比盯着任何发布会都有用。

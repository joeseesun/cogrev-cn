训练完几小时就开源：Z.ai 凭什么在榜单上跟 GPT-5.1 掰手腕

LMArena 文本榜第 19 名，Elo 分数比榜首低大约 65 分。这个差距听着不小，但换算成正面对决，它每五场能赢两场。模型叫 GLM 4.6，来自 Z.ai，中文名智谱 AI。更值得看的是榜单第 16 到 19 名挤着四个中国模型：GLM 4.6、Qwen 3 Max、Kimi K2 Thinking、DeepSeek v3.2。全球前四的开源模型，全部来自中国。

在 Web Dev 榜上 GLM 4.6 排到第 9，跟 GPT-5.1 打得有来有回，前面只剩 Gemini 3 和 Claude 4.5 Opus。这一集 ChinaTalk 请来了 Z.ai 产品与 GenAI 战略总监李紫萱，主持人有 Jordan Schneider、常驻分析师 Irene Zhang，还有 Ai2 的 Nathan Lambert。聊的内容远超榜单，涉及开源的真实动机、中国团队的发布节奏、角色扮演这种国内刚需，以及一位在 MIT 读过 AI 安全的人回国后的见闻。

先说这家公司是怎么来的

智谱 2019 年成立，最早追 AGI 的路线跟大模型没关系，做的是图网络和图计算。第一个产品叫 AMiner，用图结构把期刊论文、学者、引用关系连成一个数据库，能搜人也能搜贡献，当时在学术圈很流行。2020 年转向大语言模型，2021 年发出 GLM 论文，比 GPT-3.5 早了一年。

GLM 本身是个新架构，不是把 Transformer 拿来改改。李紫萱提到这一点时语气很平，但背后的意思是：这家公司从第一天起就在架构层面做探索，而不是等别人验证完再跟进。

真正让国际开发者记住他们的，是 2024 年到 2025 年的两次转向。2024 年全行业盯 Chatbot Arena，智谱在那上面排到第 6 到第 9。2025 年 Claude Code 出来后，团队判断编程和 agent 的经济价值更高，把重心整个挪了过去。李紫萱说得很直白：聊天机器人是免费的，没人会为它付钱，编程和 agent 才有人掏钱。

GLM 4.5 的技术报告里写了一个做法：先训三个独立模型，再蒸馏成一个。预训练团队和后训练团队坐在一起，目标只有一个，做统一的推理加 agent 加编程模型。她认为这是效率比同行高的原因之一。

开源不是信仰，是一张入场券

西方开发者常把中国公司的开源理解成某种意识形态选择，李紫萱给出的解释朴素得多。

“作为一家中国公司，你需要真的开放才能被接受。人们不会用你的 API 去试你的模型，他们可能部署在 Fireworks 上，可能在 Rock 上用，也可能下载到自己芯片上跑。所以现在必须开放，别人才会用 GLM。”

她补了一句更关键的：2024 年智谱的旗舰模型是闭源的，看到 DeepSeek R1 之后才想明白，开源和商业回报可以同时要。“你得先把蛋糕做大，再咬一口。”Nathan Lambert 在旁边接话，说自己在 Ai2 干活，确实没法直接签中国公司的 API，但训练时蒸馏过好几个中国模型。这个细节把开源的现实逻辑说透了：美国企业不会用你的接口，那就把权重放出去，让人在你的模型上做二次开发，品牌和生态自然长出来。

开源之后怎么赚钱？李紫萱的答案分两层。第一层是订阅，GLM Coding Plan 让用户按月付费，不用再盯着每一个 prompt 烧掉多少 token。她说在 Claude Code 里一轮交互可能消耗上百万 token，订阅制直接把这个焦虑拿掉了，用户黏性也上来了。第二层是工程能力，客户会问“我自己部署开源版不就行了，为什么要买你的服务”，答案只能是更快的解码速度、更好的搜索、更完整的 MCP 工具链。

她还提到一个数字感很强的判断：不需要说服 50% 的 Claude Code 用户，抢到 5% 就是巨大的市场。

一百多人的核心团队，创始人自己跑实验

问到训练模型的核心团队规模，李紫萱给的数字是 100 到 200 人。这个量级跟美国头部实验室公开的说法差不多。大公司结构不一样，比如字节会同时押文本、视频、语音几条线，资源摊到多个团队，但每个团队内部的核心成员也就 10 到 20 人，剩下 80 到 100 人做训练和数据准备。

她反复强调的一点是，负责人必须自己动手做研究、自己跑训练，不能只定目标让别人干。理由很实在：变化太快，训练进行到一半可能 GPT-5 出来了，可能别家发了新架构，你不在第一线就感受不到风向。创始人本人也读论文、跑实验。

团队里有很多在读博士生，一边念学位一边参与 GLM。李紫萱的说法是，这些人不觉得需要先把手头的论文做完再回来做模型，他们把 GLM 当成自己最大的学术成果。这种把工业项目和学位论文合并的做法，在美国的闭源实验室里很少见，在 Ai2 这种开放研究机构里倒是有类似的气氛。

关于“海归有没有被歧视”这个在中西媒体上被炒过的话题，她给了一个很具体的观察：智谱内部大概只有十个人知道她读过 MIT。没人问，也没人在意，面试标准对国内外一视同仁，谁面试表现好用谁。她说这话的时候语气平常，反而让这个细节更有说服力。

训练结束到开源，中间只隔几个小时

这一集里最让人意外的运营细节，是发布速度。

Nathan Lambert 问从训练完成到模型上线要多久，李紫萱的回答是“几个小时”。训练跑完，做一轮评估，然后就开源。没有什么提前送测 LMArena 排队的流程，也没有什么预热营销。她的解释是：如果决定开源，开源本身就是最大的事件。

这套节奏对做市场的人是折磨。李紫萱自己说，她希望能有一周时间跟推理服务商、基准测试机构、编程 agent 团队对接，让外部先试用。公司层面的逻辑是，开源材料准备好、基准跑完、技术博客写完，就可以发了。她经常在半夜接到通知，两三个小时后新模型就要上线，得在这个窗口里跟 Fireworks、LMArena、Kilo Code 这些合作方谈完。

主持人问她一天工作多久，答案是 18 个小时，因为要配合美国 CEO 的时区，会议可能排在凌晨两点。但她马上区分了工种：研究人员和工程师一天干 8 小时就够了，读论文、写代码、跑实验，脑子撑不住更久。能开 20 小时会的都是开会的人。

公司文化里还有个细节：创始人跑马拉松，全马成绩在三小时以内，公司周年庆办半程马拉松。有个实习生跑了 3 小时 15 分，李紫萱在终点等她，说人差点没缓过来。这个片段听着像闲聊，其实透出一种气质，这家公司把长跑当成一种组织隐喻。

角色扮演和表情包翻译，被忽略的中国刚需

GLM 4.5 在角色扮演上其实偏弱，因为训练数据里这类内容不多。角色扮演的特点是系统提示极长，用户会写五页纸的背景设定，比如“我是 1570 年劫掠台湾海岸的日本海盗，现在要规划一次防守”。模型如果没在这种长指令上训练过，聊几轮就会忘了自己是谁，退回到通用对话模式。李紫萱说这个问题主要靠后训练数据解决，GLM 4.6 在这方面补了很多。

她提到一个内部项目，让用户描述《恶搞之家》里 Stewie 的行为，就能生成一个自己的 Stewie。文本已经做得不错，加上语音模型就能复刻声音。

翻译是另一个被低估的方向。中英互译上她认为 GLM 跟 Gemini 2.5 Pro 打平，真正的差异在梗和表情符号。如果一句话在聊 AI，里面用了一个鲸鱼 emoji 指代 DeepSeek，模型会把它翻回 DeepSeek；如果整句在聊动物，就保留成鲸鱼。这种上下文判断靠的是对中文互联网文化的理解，不是通用翻译能力。

数据从哪来？微信和小红书的墙内数据拿不到，只能靠公开区域观察加合成数据。她特别提到 TikTok 的评论区，说那里的人说话最“皮”，是最真实的语料来源。TikTok 难民潮那波，反而给他们的翻译能力带来了企业客户。她还点出一个商业逻辑：YouTube 的自动翻译做到 80% 准确就够了，用户能看懂大意；但 X、小红书、微信评论区的翻译必须 100% 准确，错一个字客户就不买。

“有一堵墙”，架构突破还没来

Nathan Lambert 问了一个美国实验室普遍不愿正面回答的问题：靠现有 Transformer 加数据还能走多远，是不是快撞墙了。

李紫萱的回答很直接：“数据能改进，但跨不过那堵墙。确实有一堵墙，需要更好的架构。”

她讲了实验方法。GLM 4.6 是 3550 亿参数的模型，这个规模没法反复试错，所以假设验证都在 90 亿或 300 亿参数的模型上做。90% 的实验会失败。这是研究工作的常态，得靠大量科学试错才能撞对一次。

另一个被点破的行业默契是上下文窗口。她说模型可以宣称支持 100 万 token，但真正表现稳定的区间可能只有 6 万到 10 万。工程上的应对是压缩上下文到 3 万或 6 万，保证用户体验不掉。这话从一个做产品的人嘴里说出来，比论文里的数字可信得多。

训练和推理的部署也讲清楚了。训练全部在中国境内，推理服务放在新加坡，api.z.ai 由一家新加坡公司运营，数据不出海外。她解释这样做不是为了绕开管制，而是海外客户对数据存储地的要求很严，隐私政策每个月都在改得更严格。至于为什么不用 AWS 或 Nebius，答案简单：自家有芯片，没必要绕一圈。

谁在害怕 AI：开发者比普通人怕得多

Irene Zhang 问了一个价值观层面的问题：中国社会怎么看 AI 的风险。

李紫萱的观察是，真正感到恐惧的是开发者，尤其是初级开发者。他们天天用 Claude Code、用 Codex，最清楚这些工具能替掉多少活。普通用户用 DeepSeek brainstorm、润色文字、做翻译，不觉得会被取代。至于 AI 接管世界这类长期风险，她说在中国不是主流讨论，因为模型还不够强，幻觉还在，指令遵循还不稳，大家觉得这东西还挺笨的。

这个判断跟美国的舆论生态形成明显反差。Nathan Lambert 说美国有一小撮声音很大的人在讨论就业之外的深层风险，就业流失反而成了默认前提。李紫萱接过话，说她在 MIT 的时候身边人都在讨论 AI 会怎么改变世界，而且讨论的是负面那一面。

她给了一个挺扎心的解释：了解得越多，恐惧越多。中国十四亿人里可能只有一百万人跟最新趋势，剩下的人照常上班，AI 还没进到他们的工作流里。智谱内部反而不担心失业，因为活干不完，缺人。

大企业的情况不一样。她提到有些公司上万人做数据分析和后端工程，老板一旦决定用 agent 工具，可能只需要一半的人。但普通员工什么也做不了，只能等决策落地，像亚马逊正在发生的事。

榜单之外的现实：X 上两万粉，DeepSeek 一百万

有一个数字对比很能说明品牌差距。Z.ai 在 X 上有两万粉丝，DeepSeek 有一百万。李紫萱说，德国一位教授跟她聊天时提到 Llama、Qwen、Mistral，没提 GLM。而在旧金山的圈子里，聊 GLM 的人已经比聊 Mistral 和 Llama 的多了。

她承认中国科技媒体会紧盯着 Karpathy、Sam Altman、Elon Musk 的每一条推文，这些人的偏好会迅速传导回国内。智谱从 DeepSeek 身上学到的一点是，全球品牌会反过来影响国内企业客户的采购决策。以前他们觉得卖产品给中国企业就行，现在国内客户也看你在大洋彼岸的口碑。

Irene Zhang 问了一个很中国的场景：怎么跟北京的高中生或者奶奶解释你在做什么。李紫萱说很难，只能讲“我们跟 DeepSeek 做类似的事”。她说清华的学生里有很多人没试过 GLM，甚至没听过这家公司。DeepSeek 上了所有新闻和社交媒体，其他公司很难解释自己的价值。“只有最有名的那一个能拿到全部注意力。”

海外市场的分布也有意思。用户数最多的是印度，但海外收入一半来自美国，因为美国用户买 Pro 和 Max 套餐，印度用户买轻量版。获客渠道基本靠 X、Reddit、YouTube，哪里讨论热度高，哪里就出货。

接下来的路线图和几点可操作的东西

访谈末尾李紫萱透露了产品节奏：GLM 4.6 Air 和 4.6 Mini 会陆续发布，Mini 是 300 亿参数，明显更小。2025 年的发布到此为止，2026 年的实验在更小的模型上跑，暂时不会落地成产品。研究方向她点了两个：on-policy 强化学习，团队在 off-policy 上已经比较成熟；多智能体架构，现在 Z.ai 聊天里的搜索、生成 PPT、生成海报都是单个 agent 完成的，多智能体的难点在上下文压缩和编排，一个 agent 产生幻觉会毁掉整条链路。

把这一集的信息拆开，有几件事明天就能用上。

  • 评估一个模型别只看榜单排名。GLM 4.6 在 LMArena 排第 19，跟榜首差 65 分 Elo，但正面对决胜率是 40%。榜单名次和实际可用性之间隔着一段距离，Web Dev 榜上它排第 9，做前端任务时的表现跟综合排名不是一回事。
  • 如果你在做 coding agent 或推理服务，去谈 GLM 的接入。他们的开源节奏是训练完几小时就放权重，合作方在模型上线前几乎没有准备时间。提前建立联系渠道，比等发布公告再行动要快得多。
  • 上下文窗口的宣传数字要打折看。宣称 100 万 token 的模型，稳定工作区间可能只有 6 万到 10 万。设计产品时按有效窗口来做预算，别按标称值。
  • 做中文内容出海或英文内容进中国，翻译工具的选型标准要改。大意准确不够，梗、缩写、emoji 的语境判断才是分水岭。测试时拿几条带黑话的评论区留言去跑，比拿新闻稿测试有用。
  • 团队管理上，李紫萱那句话值得记住：负责人得自己跑实验。变化太快的时候，只看报表和下属汇报，感受不到风向。

这一集没有宏大的中美竞赛叙事。李紫萱的自我定位很清楚：智谱是追赶者，能在全球市场里占住一块有意义的细分，就已经很满足。她讲开源是为了被接受，讲发布速度是因为资源有限，讲恐惧是因为模型还不够强。这些约束条件拼出来的图景，比任何口号都更能说明中国 AI 实验室现在在干什么。
